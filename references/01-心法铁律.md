# 心法与铁律（公开精简版）

## 一、交易的本质

交易不是"预测明天涨跌"，而是**在不确定性里管理概率与回撤**：

- 收益来自"赔率 × 胜率 × 重复次数"，任何一笔的输赢都不重要，长期期望为正才重要。
- 你唯一能控制的是：**买什么、买多少、错了怎么办**。行情不可控，仓位与止损可控。
- 市场先生只负责报价，不负责告诉你对错；对你的答案永远只有账户曲线。

## 二、四大支柱（心性 = 术法的地基）

1. **耐心**：等得到"看得懂的位置"再出手；等不到就空仓，空仓不丢人。
2. **纪律**：计划内的交易才做；盘中起意的一律不做。
3. **认错**：止损不是失败，是成本；不认错才是失败。
4. **复利思维**：宁可少赚，不可大亏；回撤 50% 需要翻倍才能回本。

## 三、两大心理关

### 1. 克服恐高

怕高的人赚不到主升——但"敢买"不等于"乱买"：**高位只做确认后的强势票，且只做第一只**。恐高的解药不是勇气，是买点规则。

### 2. 拒绝垃圾股

低价的诱惑背后是流动性陷阱与退市风险。**只做主线里有身份、有成交、有逻辑的票**。

## 四、与心魔对话的三句自检

1. "这笔交易在我的计划里吗？"
2. "如果现在空仓，我还会买它吗？"
3. "错了我在哪里认？"

三句里有一句答不上，停手。

## 五、五条铁律（多条游资心法交叉验证）

1. **只做强势股**：与强者为伍，不与趋势作对。
2. **不抄底不猜底**：底部是走出来的，不是猜出来的。
3. **错了就认，认了就快**：亏损单不留夜（短线口径），不带情绪加仓。
4. **不把鸡蛋放一个篮子**：单票、单板块均设上限。
5. **空仓是常态**：没有把握的时候，等待就是最好的操作。

## 六、情绪周期七阶段（定性定调）

| 阶段 | 特征 | 动作方向 |
| --- | --- | --- |
| 冰点 | 亏钱效应弥漫，连板高度消失 | 空仓观察，等待破局 |
| 启动 | 出现破局板，赚钱效应回暖 | 试仓，小步进场 |
| 主升 | 主线清晰、梯队完整 | 主仓，重仓主线卡位 |
| 高潮 | 情绪亢奋、一致性加速 | 持仓为主，逐步兑现 |
| 分歧 | 龙头分歧、接力难度陡增 | 只做减法，不开新仓 |
| 退潮 | 亏钱效应扩散、炸板率飙升 | 绝对空仓，不抄底 |
| 混沌 | 主线不明、快速轮动 | 极轻仓或空仓等待 |

> 每个阶段对应的**具体仓位分档表**属完整版内容，公开版只给定性方向。

## 七、宗师金句（点到即止）

- "会买的是徒弟，会卖的是师傅，会空仓的是祖师爷。"
- "趋势来时，人人都是天才；退潮之后，才知道谁在裸泳。"
- "只做看得懂的行情，错过不可惜，做错才可惜。"
