# 风控与极端生存（公开精简版）

## 一、三层风控

止损不是事后补救，是**事前设限**：

1. **标的层**：每笔交易买入前设好止损位（技术位/逻辑位）。
2. **组合层**：单票、单板块设上限，避免风险集中。
3. **账户层**：设总账户熔断线，触发即降仓或停手冷静。

> 各层的具体比例与熔断参数属完整版内容；公开版只给原则：**先设限，再交易**。

## 二、回避强势对手盘

某些交易对手拥有信息、资金或筹码优势，与他们站在对立面等于送钱。典型类型包括：高度控盘的资金、一字独大的筹码结构、加速期的独食行为、极端行情中的反向加速。

**回避 = 避掉大部分大回撤。**识别特征与完整清单属完整版。

## 三、赚钱效应与总仓位

总仓位的天花板由**赚钱效应**决定：市场越冷，上限越低；这是硬纪律，不是参考建议。

操作口径：赚钱效应分档 → 得到总仓位上沿 → 与情绪周期档位取**更严**者 → 才轮到选股。

## 四、仓位的数学

- 先估期望：**E = p × b − (1 − p)**，E ≤ 0 的交易不做（p 为胜率估计，b 为盈亏比）。
- 再算凯利：**f = (bp − q) / b**，实战用**半凯利**以求稳健。
- 最后取"半凯利仓位"与"仓位档"的**更严者**。

仓位是推导出来的，不是感觉出来的。

## 五、极端行情生存八法则（要点）

1. 承认极端：流动性会消失、跌停会连续，不预设"跌不动了"。
2. 先活下来：极端行情第一目标是保护本金，不是抢反弹。
3. 不接飞刀：下跌中继与止跌企稳是两回事，等确认。
4. 不加杠杆、不摊平成本。
5. 保持现金：现金是极端行情里唯一有选择权的东西。
6. 复盘分类：把极端行情存档，作为下一次预警的样本。
7. 控制情绪：连续亏损后强制降低操作频率。
8. 体系优先：极端行情是检验体系的时刻，不是推翻体系的理由。
